**Read the full page:** https://claude-code-plugins.github.io/

Plugins are listed by Anthropic as one of Claude's capabilities, alongside Skills, Connectors, Artifacts and Design, and Claude Code itself is bundled into the paid plans rather than sold separately. That makes the decision less about the plugin system and more about whether a subscription earns its place in your month. For a developer already living in a terminal with an agent, it probably does.
